# Estudos de Front-end — Alura

Repositório de exercícios de **HTML e CSS** desenvolvidos durante meus estudos de front-end na Alura.

Os projetos registram a prática de estruturação de páginas, estilização, organização de layouts e uso de imagens e fontes. Cada exercício está em sua própria pasta.

## Exercícios

| Projeto | Conteúdo | Código |
| --- | --- | --- |
| **Barbearia Alura** | Página de apresentação de uma barbearia, com banner, textos e seção de benefícios. | [barberShopAlura](./barberShopAlura/) |
| **Página de apresentação pessoal** | Exercício de portfólio com apresentação, fotografia e links, organizado com Flexbox. | [projetoFigma](./projetoFigma/) |
| **AluraPlay** | Estrutura visual de uma página de vídeos, com cabeçalho, menu, categorias e rodapé. | [aluraPlay](./aluraPlay/) |

## Tecnologias e conceitos

**HTML e CSS**, com imagens locais e fontes do Google Fonts em parte dos exercícios.

O código contém exemplos de:

- Estruturação de títulos, textos, listas, imagens e links.
- Seletores, classes, espaçamentos, cores e tipografia em CSS.
- Organização de layout com `inline-block` na Barbearia e Flexbox na página de apresentação pessoal.
- Variáveis CSS, estados de interação e media queries no AluraPlay.

## Como visualizar localmente

Baixe o repositório como ZIP e extraia os arquivos, ou utilize o Git:

```sh
git clone https://github.com/juniorptboss/Alura-Front-End.git
cd Alura-Front-End
```

Na pasta obtida, abra no navegador o `index.html` do exercício desejado:

```text
barberShopAlura/index.html
projetoFigma/index.html
aluraPlay/index.html
```

Mantenha os arquivos nas respectivas pastas para preservar os caminhos de estilos e imagens. Não há etapa de compilação ou instalação de dependências para essas páginas. As fontes externas precisam de conexão com a internet para carregar.

## Escopo das versões disponíveis

**Barbearia Alura:** contém uma página estática de apresentação. Não inclui formulário de contato, agendamento ou processamento de pedidos.

**Página de apresentação pessoal:** é um exercício de layout. O texto biográfico pertence à época do estudo e não deve ser tomado como uma apresentação profissional atualizada.

**AluraPlay:** contém a estrutura e os estilos da interface. A lista de vídeos está vazia no HTML; a pesquisa e os links de navegação com `href="#"` não implementam uma busca ou navegação entre páginas.
